# Payroll-to-LohnundGehalt

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
## Description

Takes payroll-related files (Lohnjournal, Personalkosten, payslips) and converts them into a Lohn-und-Gehalt-compatible input file. This project aims to streamline the process of transferring payroll data to Lohn-und-Gehalt software. This is a web app for easy deployment and upkeep. Only the three files are required to make the new one.

## Features

- Converts payroll data from various formats (Lohnjournal, Personalkosten, payslips).
- Generates Lohn-und-Gehalt-compatible input files.
- Uses a modern JavaScript framework (Vite) for a smooth user experience.
- Includes styling with CSS and potentially Sass.


## Tech Stack / Key Dependencies

- JavaScript
- CSS
- HTML
- Vite
- Sass
- date-fns

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/JoHoe11/Payroll-to-LohnundGehalt.git
   cd Payroll-to-LohnundGehalt
   ```
2. Install dependencies:
   ```bash
   npm install
   ```

## Usage / Getting Started

1.  Start the development server:
    ```bash
    npm run dev
    ```

2. Build the project:
   ```bash
   npm run build
   ```

3. Preview the build:
   ```bash
   npm run preview
   ```
